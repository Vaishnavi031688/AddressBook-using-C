# AddressBook-using-C

Project Description
This Address Book project for managing contact details. It lets users create, search, edit, delete, and list contacts with fields like name, phone number, and email. The program stores contact data in a text file so the information persists even after the application is closed.


**What the project does**

1.Add new contacts
2.Search for contacts by name, phone number, or email
3.Edit existing contacts
4.Delete contacts
5.List all contacts
6.Save contacts to a file
7.Load saved contacts when the program starts

**Main project files**

1.main.c
  Contains the menu and the main program loop. This is the entry point of the app.
2.contact.h
  Declares the Contact and AddressBook structures and function prototypes.
3.contact.c
  Implements the core logic for create, search, edit, delete, and list operations.
4.file.h
  Declares file-related functions.
5.file.c
  Saves contacts to and loads contacts from the file.
6.contacts.txt
  Stores contacts in text form
